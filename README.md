# HBIF26 - Himpunan Badminton Informatika 26
Website profil komunitas Himpunan Badminton Informatika angkatan 2026. Website ini berfungsi sebagai sarana informasi kegiatan rutin, pengenalan komunitas, serta kontak narahubung bagi anggota.

## Latar Belakang & Tujuan

Website statis ini dibuat untuk memperkenalkan komunitas badminton di lingkungan Informatika angkatan 26. Tujuannya mempermudah koordinasi jadwal latihan rutin, menyediakan wadah komunikasi bagi peminat olahraga bulu tangkis, dan mendokumentasikan kegiatan olahraga bersama.

## Fitur & Section Website

* Home / Hero Section: Sambutan utama, nama komunitas, dan tombol navigasi.

* About / Profile: Profil latar belakang komunitas dan visi HBIF26.

* Main Content: Jadwal latihan rutin mingguan dan agenda kegiatan.

* Contact & Footer: Tautan media sosial dan informasi kontak pengurus.

## Teknologi yang Digunakan

* HTML5

* CSS3

* JavaScript dasar
